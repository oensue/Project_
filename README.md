# 🍉 자취생의, 냉장고를 부탁해!

## 1. 무엇을 하는 프로그램인가요?
- **개요**: 자취생이 식재료 관리에 미숙하여 유통기한이 지난 음식을 버리거나 생필품 재고를 놓쳐 당황하는 일상의 불편함을 해결하기 위한 생활 밀착형 관리 도구입니다.
- **주요 목적**: 품목 이름, 수량, 유통기한을 등록하고, 오늘 날짜를 기준으로 기한이 임박한 물품을 파악하여 낭비 없고 건강한 자취 생활을 돕고자 제작되었습니다.

---

## 2. 실행 방법
1. **환경 준비**: 컴퓨터에 Python 3.10 이상 버전이 설치되어 있어야 합니다.
2. **실행**: 터미널 또는 명령 프롬프트(CMD) 창에서 프로그램이 있는 폴더로 이동한 후 다음 명령어를 입력합니다.
   *python "자취생의, 냉장고를 부탁해!.py"*
3. **데이터 저장**: 프로그램 종료(5번 메뉴) 시 동일한 폴더 내에 `inventory.txt` 파일로 현재 냉장고 데이터가 자동 저장 및 업데이트됩니다.

---

## 3. 사용된 Python 개념
- **변수 및 자료형**: 
**딕셔너리(`{}`)** 품목 하나의 정보를 가독성 높게 관리하기 위해 사용
**리스트(`[]`)** 전체 냉장고 데이터를 유연하게 묶기 위해 자료구조를 조합해 사용

- **제어문**: 
**`for` 반복문** 전체 재고를 순회하며 출력
**`if` 조건문 & 예외 처리(`try-except`)** 오기입을 방지하는 다중 검증 루프 구현

- **함수화**: 
기능의 확장과 관리를 용이하게 하기 위해 **등록(`add_item`), 조회(`show_list`), 알림(`check_expiry`), 수정/삭제(`update_or_delete_item`)** 등으로 기능을 명확히 쪼개어 모듈화

## 4. AI 도구 사용 내역
부가적인 고도화 기능 구현을 위해 아래와 같이 AI(Gemini)를 활용하여 보완함

* **1) 오기입 데이터 수정 및 삭제 로직 구현**
  - **받은 도움**: 리스트 내에 중첩된 딕셔너리 중 사용자가 원하는 특정 품목을 찾아서 구조를 변경하거나, `inventory.remove()`를 사용하여 안전하게 데이터를 삭제하는 조건문 흐름을 조언받았음.
  - **내 판단 및 검토**: 단순 삭제를 넘어 수량이나 기한을 수정할 때 기존 값을 유지하고 싶으면 '엔터'를 쳐서 넘어갈 수 있는 예외 처리 코드를 직접 덧붙여 사용성을 한층 개선함.

* **2) 텍스트 파일 데이터 복원 (`load_data` / `save_data`)**
  - **받은 도움**: 프로그램을 종료해도 데이터가 사라지지 않도록 파일 시스템에 구조화하는 방식(`write()`)과, 저장된 텍스트의 각 라인을 읽어와 공백을 제거(`strip()`)하고 쉼표를 기준으로 문자열을 분할(`split(",")`)하여 원래의 자료구조로 복원하는 입출력 로직을 추천받음.
  - **내 판단 및 검토**: 초기 실행 시 파일이 존재하지 않으면 프로그램이 비정상 종료되는 `FileNotFoundError` 무결성 문제를 발견함. 이를 해결하기 위해 `try-except` 예외 처리 구문을 도입하여, 데이터 파일이 없는 첫 실행 환경에서도 에러 없이 부드럽게 새 파일을 생성하고 진입할 수 있도록 예외 흐름을 검토 및 보안하여 반영하였음.

## 5. 한계와 다음 단계 (구체화 버전)

### 📌 유통기한 정렬 및 시각적 우선순위의 한계
* **현재 상황**: 전체 재고 리스트를 조회할 때 품목들이 유통기한 순서가 아닌 사용자가 등록한 순서대로 출력됨. 따라서 냉장고 안의 물품이 많아질 경우, 당장 어떤 물품이 가장 먼저 만료되어 버려질 위험에 처했는지 직관적으로 파악하기 어렵고 일일이 알림 메뉴를 따로 확인해야하는 번거로움이 발생함.
* **다음 단계**: 파이썬 리스트의 내장 정렬 기능을 추가 학습 및 적용하여, 전체 조회 시 자동으로 유통기한이 가장 적게 남은 순서(오름차순)로 정렬하여 출력하도록 화면 흐름을 개선하고 싶습니다.

### 📌 다량의 물품 관리 시 시각적 인지 한계와 카테고리 분류
* **현재 상황**: 냉장고 안의 물품이 많아질 경우 모든 재고가 하나의 리스트로만 나열되어 시각적으로 복잡해짐.
* **다음 단계**: 품목 등록 시 **유제품, 야채, 과일 등 '카테고리'** 속성을 함께 입력받아 저장하고, 전체 조회 시 카테고리별로 묶어서 필터링해 볼 수 있는 분류 기능을 추가하여 다량의 물품도 체계적으로 관리할 수 있도록 발전시키고 싶습니다.

### 📌 CLI 환경의 접근성 한계 및 웹페이지 확장
* **현재 상황**: 터미널 창(CLI) 기반으로 동작하기 때문에 VS코드 같은 별도의 개발 환경이나 복잡한 프로그램 실행 과정이 필요하여, 코딩을 전혀 모르는 일반 사용자들에게 사용하게 했을 때는 다소 진입 장벽이 있었음.
* **다음 단계**: 일반 사용자들도 VS코드 없이 인터넷 브라우저를 통해 링크 하나로 쉽게 접속하고 이용할 수 있도록, HTML/CSS 지식과 파이썬을 결합하여 디자인적으로 예쁘고 직관적인 UI를 갖춘 웹사이트 형태로 서비스를 확장하고 싶습니다.
